# Catalog discovery extension

Mode: Operate. Target: existing home catalog and /plugins/.

## Direction contract

THESIS: Find an agent capability, then choose how to install it. Plugins and Skills are distinct modes of the same catalog; installation controls appear only after intent.

OWN-WORLD: Preserve the incumbent registry typography, light/dark surface tokens, accent, control geometry and existing agent multiselect. Extend shared components rather than copying card or input styles. No new decorative hero.

STORY: A visitor switches to Skills, searches or browses real skills.sh entries, inspects a GitHub source, clicks Install, chooses agents and copies the exact command. The CLI resolves and reviews actual source contents.

FIRST VIEWPORT: Two prominent URL-addressable Plugins/Skills tabs above the existing full-width search and compact view selector; real result cards below. No empty basket, agent panel or terminal instructions competing with browsing. Selected installation opens within its card using the existing controls.

FORM: Precisely specified extension of an established catalog. No new visual-world or concept-seed round is applicable. Desktop-first; keyboard access, visible focus, honest loading, stale, empty and error states.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
