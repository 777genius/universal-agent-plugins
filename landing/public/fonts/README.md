# Local site fonts

These are the unchanged Google Fonts WOFF2 files used by the site: Inter v20
(weights 400, 600, 700, 800) and JetBrains Mono v24 (weights 400, 600).
The Unicode subsets and `font-display: swap` declarations are preserved in
`fonts.css`. Stylesheet-relative URLs keep font requests on the selected
site origin at both root and repository deployment bases.

`sources.json` records the original versioned URLs, byte lengths and SHA-256
hashes. Each family is distributed under its included SIL Open Font License 1.1
notice. The files are served locally so page loading does not depend on Google
Fonts availability; the existing system font fallbacks remain unchanged.
