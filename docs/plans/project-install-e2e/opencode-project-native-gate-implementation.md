table contains four Git setup commands, fourteen UAP operations and twenty-five
OpenCode observations. Live stdout/stderr caps and per-command plus fixture

skill paths/content and MCP marker config, unchanged add/update/intact repair,

installation_verified. Original user state/config/control, B installed state,
foreign comments/settings and caller-owned data are preserved. Secondary
same-name and inline observations retain actual winners and unrecognized
warnings as blocked evidence; they cannot replace mandatory positive discovery.
The short JSON route records actual file format and exact removal separately.

The passive loopback endpoint counts accepted TCP and HTTP requests, returns503

tool, model, auth, trust, enterprise/ancestor, IDE or default-plugin proof follows.
Vendor bootstrap/cache/download effects are explicitly distinct from ownership.

admits captured bytes under a cumulative32MiB/128file envelope and atomically
