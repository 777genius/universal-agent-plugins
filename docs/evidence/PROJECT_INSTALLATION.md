## Read the retained records and raw snapshots

Interpretations, provenance, curated results, archive/member manifests and two
local Claude probes remain in the current tree. Expanded raw command outputs
are archived in the original immutable merge tree. **Raw snapshot** links below
use the full merge SHA, so they do not depend on Actions artifact retention.
Run/job/artifact identities, client/source pins, archive digests and original
member hashes remain in the linked metadata where recorded; absent IDs are not
invented. JSON member maps describe the original snapshot, not the smaller
current directory. Retained summaries may contain selected original outputs.
Each Git snapshot contains the files originally committed in that observation
directory. Provider ZIP inventories can include additional members whose location
is described in the original provenance.

For example, retrieve an original raw member from a clone containing that commit:

```sh
git show 3b93148c356fc5db6fe101d81d943160a5176b6d:docs/evidence/project-scope-research/vscode-1.143.1-untrusted-workspace-linux-amd64-40188310034/A.merged.log
```

No observation here establishes successful real-model use or authentication
unless its own record explicitly says so. File ownership, native discovery,
MCP initialization/tool use, trust and process/network isolation remain distinct.
