## Objective and evidence boundary

Reproduce the public user's installation path for **30 distinct complete Agent Plugins 1.0 packages** and **30 distinct standalone Agent Skills 1.0**, against **every adapter advertised in README**. Test acquisition, real CLI installation, persistent/native output, idempotent replay and safe cleanup. Use isolated profiles and exact source identities. ## Plan of work

1. **Inventory and plan critique.** Read current CLI target/command contracts, signed directory and existing live E2E harness. Select reproducible public sources; reject untrusted/malicious or unsupported entries. Critique scope/security/observability before implementation.
2. **Live acceptance harness.** Reuse the public CLI, existing GitHub-hosted Actions setup and isolated temp profiles. No mock HTTP, mock installer, synthetic `SKILL.md`, guessed native paths or global user writes. Keep deterministic fixtures, bounded timeouts and per-case evidence; report all cases rather than stop at first failure. Run source sets across all *supported* adapters, splitting workers by target to avoid unnecessary sequential runtime.
3. **Reproduce and triage.** Compare exit status with native filesystem and owned-state evidence. For every confirmed bug record **ID, severity, source, target, CLI SHA/version, exact command, expected/actual, logs, root cause, minimal fix plan and regression** below. Failures due to third-party source/network/auth must be identified separately.
4. **One PR, narrow fixes.** Fix only reproduced installer bugs in their existing module/adapter. No feature flags, wholesale refactors, new APIs, unrelated UX, VS Code changes or release publication. Push immediately after each commit.
5. **Qualification and merge.** Re-run live cases on the final head, existing focused tests and required CI. Two independent review passes (security/data loss; architecture/behavior/regressions), then review comments, fixes and re-runs until all critical/actionable findings are resolved. Merge only after all qualifying checks are green and an honest evidence summary is committed.
