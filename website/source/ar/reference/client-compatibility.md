# أدلة توافق عملاء UAP {#uap-client-compatibility-evidence}

## الإصدار الحالي ونطاقه {#current-release-and-scope}

يضيف [CLI 0.1.94](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.94)، الإصدار الأصلي المنشور في 28 أكتوبر 2026، الاختيار التلقائي للمشروع عند تشغيل `install` دون وسيطة مصدر إذا احتوى المجلد الحالي نفسه على ملف عادي باسم `uap.toml`. تكون الأولوية للنطاق الصريح، ولا تُبحث المجلدات الأب. تُفحص الأقفال الموجودة بصرامة حتى دون `--locked`. أُضيف التسليم الصريح ضمن نطاق المشروع في 0.1.93. لا تؤهّل أدلة إصدار المثبّت هذه تشغيل كل وكيل أصلي أو الملف التنفيذي للتأليف المعياري. لا يتضمن المثبّت الحالي عبر npm أو التثبيت الأصلي `agentplugins author`؛ راجع [دليل البناء](../build/) لأدوات المصدر.

اقرأ التوافق بوصفه عدة أسئلة منفصلة:

| الفحص | المعنى |
| --- | --- |
| مطابقة الحزمة | تستوفي ملفات الحزمة المعيارية عقد المحمّل والمخطط. |
| تسليم المكونات | جهّز المحوّل المكونات التي يملكها أو ثبّتها. |
| الاكتشاف الأصلي | رصد عميل معين المكوّن المقصود. |
| تشغيل MCP | تهيّأت عملية أو وصلة مسجلة وأجرت الاستدعاءات المختبرة. |
| المصادقة واستخدام النموذج | لا يثبتان إلا إذا اختبرتهما الأدلة صراحةً. |

غالبًا ما يبقى تسليم المشروع **Prepared** ما دام هناك عمل متعلق بالثقة أو إعادة التحميل أو الإعداد الصريح أو الجلسة. تثبيت مشاريع ChatGPT غير مدعوم صراحةً. يجهّز نطاق المشروع في VS Code ملفات لمجلد محلي واحد؛ ولا تُعد ملاحظة بياناته الوصفية المثبتة دليلًا على بدء MCP أو تنفيذ النموذج. راجع [دعم المشاريع حسب العميل](https://github.com/777genius/universal-agent-plugins/blob/main/docs/PROJECT_CLIENT_SUPPORT.md) و[فهرس أدلة المشاريع](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/PROJECT_INSTALLATION.md).

تحافظ السجلات أدناه على الإصدارات التاريخية الدقيقة وإصدارات العملاء وهويات المنصات والقيود المرصودة. ولا تنطبق تلقائيًا على 0.1.94 أو إصدار عميل لاحق أو نطاق آخر أو حزمة غير مختبرة. UAP أدوات مجتمعية مستقلة؛ وهذه ملاحظات محدودة أجراها القائمون على الصيانة، وليست اعتمادًا من المزوّد أو ادعاء بجاهزية شاملة للإنتاج.

## المثبّت التاريخي المسوّدة 0.1.55 {#historical-draft-installer-0155}

**عند نقطة التحقق المسجلة في سبتمبر 2026، كان 0.1.55 مسوّدة غير منشورة.** تؤهّل هذه النتائج لقطات المسوّدة تلك؛ ولا تصف حالة الإصدار الحالية أو تقدم تعليمات ترقية. تبقى أدلة الإصدار المنشور 0.1.53 أدناه صالحة ومنفصلة.

عبر نطاقين مؤهّلين على نحو مستقل، **اجتاز 12 مسارًا للعملاء الأصليين الاختبارات العليا المطلوبة كلها، وعددها 24، دون تخطٍّ**. استخدم كل منها أرشيف npm الأصلي من عملية الإنتاج، وتثبيت npm بلا اتصال مع تعطيل البرامج النصية، وتهيئة باردة من الملف التنفيذي الأصلي المجمّد، ثم تشغيلًا دافئًا دون مصدر الإثبات. بعد ذلك شُغّلت نسخ العملاء الحقيقية المثبتة الإصدارات في ملفات تعريف مؤقتة جديدة.

| العميل المختبر | Linux arm64 | Linux amd64 | macOS arm64 | Windows amd64 |
| --- | --- | --- | --- | --- |
| Codex 0.153.4 | اجتازت دورة الحياة وstdio/HTTP وسياق Skill | اجتاز النطاق نفسه | اجتاز النطاق نفسه | اجتاز النطاق نفسه |
| Claude Code 2.1.263 | اجتازت دورة الحياة وstdio/HTTP وSkills المثبّتة | اجتاز النطاق نفسه | اجتاز النطاق نفسه | اجتازت دورة حياة HTTP وSkill المثبّتة؛ stdio المُدار غير مدعوم |
| OpenCode 1.18.29 | اجتازت دورة الحياة وحزم اختبارات stdio/Skill الموسعة ورصد التعارض | اجتاز النطاق نفسه | اجتاز النطاق نفسه | اجتاز النطاق نفسه |

تغطي دورة الحياة التثبيت والتحديث وإعادة تهيئة الإصدار نفسه والإصلاح والإزالة. يبلغ Claude على Windows عن `managed_stdio_platform_unsupported`؛ ولم يثبت تشغيل stdio أو سلوك cwd/argv/env/data لديه. يبقى تعارض OpenCode المرصود دون حل، مع التنبيه `opencode_tool_namespace_not_evaluated`. لا تثبت دورة حياة JSONC تشغيل stdio أو متن Skill ضمن JSONC. ولا تمثل نقطة اختبار جلب Git في Codex ادعاءً جديدًا بتشغيل أصلي عبر Git عام.

اجتاز [التشغيل التاريخي ذي المسارات التسعة](https://github.com/777genius/universal-agent-plugins/actions/runs/34309083566) تسعة مسارات و18 اختبارًا مطلوبًا باستخدام إطار الاختبار `0cfa2b7`؛ وكان آخر تحقق من المسوّدة في **2026-09-09T04:10:39.529018+00:00**. واجتاز [تشغيل Linux amd64](https://github.com/777genius/universal-agent-plugins/actions/runs/34307075390) ثلاثة مسارات وستة اختبارات مطلوبة باستخدام `fde7298`؛ وكان آخر تحقق من المسوّدة في **2026-09-09T03:36:42.614887+00:00**. يرتبط كلاهما [بتشغيل الإنتاج](https://github.com/777genius/universal-agent-plugins/actions/runs/34305637370) المجمّد نفسه. تسجل [بيانات الأدلة الوصفية الموجزة](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/client-compatibility-draft-0.1.55.json) هويات الإنتاج والحزمة وإطار الاختبار والتأهيل والأرشيف الدقيقة.

اجتاز النطاقان المحتفظ بهما التحقق بلا اتصال. وأعادت نسخة جديدة من أداة التحقق عند `0cfa2b7` فحص نطاق Linux amd64 المحتفظ به عند `fde7298` أيضًا؛ ولم يكن ذلك تشغيلًا أصليًا جديدًا أو إعادة فحص حية للمسوّدة، ولا يضيف وقت تأهيل. ليس اتساق بصمات الأرشيف تحققًا جديدًا من الإقرارات أو دليلًا على حالة المسوّدة الحالية. تبقى السجلات الخام والأرشيفات خاصة إلى حين مراجعة الإفصاح؛ والمتاح علنًا هو البيانات الوصفية فقط.

هذه ملاحظات أجراها القائمون على الصيانة باستخدام عملاء حقيقيين ومزوّدي نماذج loopback مبرمجين وإتاحة الشبكة. لا توفر ملفات التعريف المؤقتة وبيئات العمليات الفرعية الصريحة عزلًا على مستوى نظام التشغيل أو العمليات. ولا يترتب عليها ادعاء عن نموذج حقيقي أو OAuth أو تسجيل الدخول أو تطبيقات سطح المكتب أو خدمات حية أو اعتماد من المزوّد أو صفة رسمية أو تبنٍّ مستقل. تظل صلاحية الحزمة والتثبيت والتفعيل والتشغيل وOAuth طبقات أدلة منفصلة. ولا يؤهّل إثبات المثبّت هذا إصدار الملف التنفيذي للتأليف المعياري (D5).

## ملاحظات تاريخية لبناء المصدر {#historical-source-built-observations}

اللقطة: **2026-09-07**. هذه ملاحظات محدودة لواجهة CLI الأصلية الخاصة بالمثبّت `agentplugins`. لا تثبت دعم كل إصدار لعميل أو تطبيق سطح مكتب أو نظام تشغيل أو حزمة أو مسار مصادقة. UAP أدوات مجتمعية مستقلة؛ وهذا الجدول ليس اعتمادًا من المزوّد.

### حدود المصدر والإصدار التاريخيين {#historical-source-and-release-boundary}

نقطة تحقق macOS/Windows أدناه هي `ef20b93`؛ وتحتفظ أدلة Linux بهويتها التاريخية المنفصلة. لا تُنقل أي نتيجة ضمنيًا إلى SHA آخر.

استخدمت تشغيلات Linux أدناه **مثبّتًا مبنيًا من المصدر**، ببصمة SHA-256 للملف التنفيذي `3e5d4b8ee25a16d274b0f3bbdaf35f6963416650fed972995e65817f274cf8d8`، من شجرة المنتج `dcd9090458b036515c9aed77ee5d3e66f0dcb4f5`، والالتزام الأساسي `1c831fa8b2016fda68c73fc60fe6f691581d0b13`، وبصمة SHA-256 للرقعة الثنائية ذات الفهارس الكاملة `d768da15903e0db5138dab72d2dbf8c94fbb5ca2e3b46f06492cbd3ac2bcaa42`.

دُمج العمل في [PR #184](https://github.com/777genius/universal-agent-plugins/pull/184) بالالتزام [`7d17c77599306d662e0bec0e0fd77d35a4f8941c`](https://github.com/777genius/universal-agent-plugins/commit/7d17c77599306d662e0bec0e0fd77d35a4f8941c). تحدد هذه التشغيلات التاريخية شجرة المنتج المختبرة قبل الدمج، وليست إعادة تشغيل وقت التنفيذ لذلك الالتزام المدمج. أحدث إصدار تم التحقق منه للقطة المصدر في 2026-09-07 هو **0.1.51 ‏(2026-09-06)**، وهو **لا يتضمن** PR #184. لا تطبّق نتائج تشغيل النسخة المرشحة هذه على الملف التنفيذي المنشور.

تسجل [هويات الأدلة الموجزة](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/client-compatibility-2026-09-07.json) بصمات الصورة والعميل والمثبّت والاختبار والاستقصاء والاستدعاء والسجلات لكل من `codex-03` و`claude-03` و`opencode-03` و`git-01` و`opencode-extended-11` المدقق مستقلًا. لا تُرفق النصوص الخام بهذا الملخص؛ فالبصمات تحدد الأصول المحتفظ بها، ولا تمثل أرشيف نصوص يمكن إعادة تشغيله علنًا.

### القيود التاريخية والإثباتات الأضيق {#historical-limitations-and-narrower-proofs}

- **تعارض أسماء أدوات OpenCode:** تعمل المفاتيح المنطقية `api/server` و`api server` منفردة، لكنها تعرض معًا اسمًا واحدًا قابلًا للاستدعاء هو `api_server_inspect_runtime` رغم ظهور فهرسي MCP كليهما. الحفاظ على مفتاح الإعداد لا يعني فرادة الاسم القابل للاستدعاء. تضيف نقطة المصدر `c154185` التنبيه `opencode_tool_namespace_not_evaluated` إلى مخرجات التسليم في CLI. وهو يحذر من تركيبات تشغيل متعارضة غير مدعومة؛ ولا يعيد تسمية الأدوات أو يثبت فرادتها أو يبطل حزمة معيارية.
- تثبت حالات اختبار OpenCode عبر HTTP الحفاظ على الإعدادات الخارجية في JSON/JSONC ورفض التعارضات. يثبت تشغيل JSON العام المنفصل `opencode-extended-11` قيم cwd وargv/env في stdio، وتوسيع الرموز مرة واحدة فقط، واستمرارية البيانات. تغيب الأدوات وبيانات Skill الوصفية بعد الإزالة، دون نشاط استقصاء، مع رصد طلب حقيقي للمزوّد الرئيسي. لا تُستنتج تغطية stdio أو المتن في JSONC.
- استبعد Codex نقل SSE وSkills غير الصالحة وبيئات التشغيل المفقودة؛ وعزل فشل بدء الملف التنفيذي؛ وأبقى الاستدعاءات السليمة تعمل؛ ورفض المدخلات غير المدعومة بالكامل دون تغيير. لم يختبر Claude مصفوفة الإخفاقات كاملة. وأثبت OpenCode استبعاد SSE مع مكونات شقيقة سليمة، وليس مصفوفة Codex الكاملة.
- رصد Codex أولوية بروتوكول HTTP وترويساته وإعادة توجيه لم يتبعها العميل عبر أصل مختلف. أثبت Claude وOpenCode استدعاءات HTTP دون اختبار مستقل لسلوك إعادة التوجيه أو أولوية الترويسات.
- أثبت Codex وClaude الحماية الساكنة للمحتوى الخارجي والتغييرات غير المتوقعة ضمن حالات اختباريهما. تغطي اختبارات انحدار منفصلة حالات التسابق أثناء التراجع عن النشر؛ وليس هذا ضمانًا ضد عمليات كتابة متزامنة اعتباطية إلى نظام الملفات.
- أثبت `git-01` الجلب الفعلي من Git عام غير قابل للتغيير والتثبيت والتفعيل والاكتشاف الأصلي لـ Skill في Codex والإزالة. كانت حالة اختباره المقتصرة على Skill هي [AP-6.2-MISSING-LOCATION-OK عند التزام مجموعة الاختبارات المثبت](https://github.com/Booyaka101/agent-plugins-conformance-kit/tree/4d163c6281a9b4929f482f387efe340b4dc175a1/fixtures/core/AP-6.2-MISSING-LOCATION-OK/plugin). انتهت إتاحة الشبكة قبل الاكتشاف الأصلي. لم يُقيّم تنفيذ MCP عبر Git أو التحويل والتحديث غير القابلين للتغيير. ولم تُقيّم تشغيلات Git الأصلية لـ Claude أو OpenCode. لا يتطلب التثبيت المحلي أو عبر Git غير قابل للتغيير وجود Directory.

### نقطة المصدر التاريخية على macOS arm64 وWindows amd64 {#historical-macos-arm64-and-windows-amd64-source-checkpoint}

اجتاز [تشغيل GitHub Actions رقم 34158664586](https://github.com/777genius/universal-agent-plugins/actions/runs/34158664586) مسارات العملاء الأصليين الستة المطلوبة كلها دون تخطٍّ، عند التزام المصدر [`ef20b9314b69d4094f4922946b8ad39024371202`](https://github.com/777genius/universal-agent-plugins/commit/ef20b9314b69d4094f4922946b8ad39024371202)، والشجرة `4ba999db51304b056ec559c5429ed9aab9aace60`. تم التحقق من **بصمات الأصول المفهرسة الـ348 كلها**. هذا دليل أصلي لنقطة بناء المصدر الدقيقة تلك، وليس للمثبّت التاريخي على Linux أو لملف تنفيذي منشور، ولا ادعاء بأن جميع بوابات جودة المستودع والإصدار قد اجتازت.

| العميل المختبر | macOS arm64 | Windows amd64 |
| --- | --- | --- |
| Codex 0.153.4 | اجتازت دورة الحياة الأصلية وتشغيل stdio/HTTP وسياق Skill المبرمج | اجتازت دورة الحياة الأصلية وتشغيل stdio/HTTP وسياق Skill المبرمج، بما في ذلك الإزالة وتكرار فحص الإزالة وحفظ المحتوى الخارجي |
| Claude Code 2.1.263 | اجتاز الاكتشاف الأصلي ودورة تشغيل stdio/HTTP المبرمجة | اجتازت دورة حياة HTTP وSkill المثبّتة؛ stdio المُدار غير مدعوم صراحةً |
| OpenCode 1.18.29 | اجتازت الحزم الثلاث: دورة حياة JSON/JSONC، وstdio ومتن Skill الموسعان، وتعارض أدوات HTTP | اجتازت الحزم الثلاث: دورة حياة JSON/JSONC، وstdio ومتن Skill الموسعان، وتعارض أدوات HTTP |

يشمل اجتياز دورة الحياة لدى Codex وOpenCode التثبيت وتحديث الإصدار وإعادة تهيئة الإصدار نفسه والإصلاح والإزالة. تثبت حزمة JSON العام الموسعة في OpenCode بصورة منفصلة استمرارية stdio cwd/argv/env/data ومتن Skill الصادر؛ ولا يعني ذلك تغطية stdio أو المتن في JSONC أو حل تعارض أسماء الأدوات المرصود. يختبر Codex أيضًا الجلب غير القابل للتغيير ضمن حزمته الأصلية. تظل صلاحية الحزمة المعيارية منفصلة عن ملاحظات العملاء هذه.

**عقد تشغيل Claude على Windows أضيق.** اجتازت مراحل HTTP الأصلي وSkill المثبّتة A/B/C والإصلاح والإزالة، مع التحقق من احتفاظ المثبّت بالبيانات. يبلغ stdio المُدار عن تشخيص الجاهزية الدقيق `managed_stdio_platform_unsupported`. رُصد عدم دعم تشغيل stdio، ولم يُقيّم سلوك stdio cwd/argv/env/data. لا يبطل قيد المنصة الصريح هذا الحزمة القابلة للنقل أو يمنع مكونات HTTP وSkill السليمة المختبرة.

كانت هذه آلات مؤقتة تستضيفها GitHub مع ملفات تعريف ومشاريع اختبار جديدة. لم تُسجل إصدارات أنظمة التشغيل في سجلات المشغّلات الموجزة. **لم تكن الشبكة محظورة**؛ وكانت نقاط نهاية النماذج خدمات loopback مبرمجة. توجد بصمات العميل والبناء وأدلة المشغّل الدقيقة في السجل الموجز. ولا ينتج عن هذه التشغيلات ادعاء بشأن نموذج حقيقي أو تسجيل الدخول أو OAuth أو تطبيقات سطح المكتب.

تتطابق حالات الاختبار الأصلية وغلاف المشغّل وسير العمل الأصلي بايتًا ببايت مع نقطة `a6462a7` التي روجعت مستقلًا. أُعيد استخدام مراجعتها الدلالية، بينما خضعت بصمات أصول التشغيل الجديدة لتحقق مستقل. ولا يحل ذلك محل مراجعة تغييرات المنتج الأخرى بين الالتزامات.

تبقى النقاط الأقدم، بما فيها مسارات Windows الفاشلة، ضمن هويات الأدلة كسجل تاريخي. يحل هذا التشغيل محل ملخص منصاتها؛ ولم يُعَد تصنيف إخفاقاتها على أنها نجاحات.

## أدلة نطاق المشروع {#project-scope-evidence}

نُشر التسليم الصريح للمشاريع في CLI 0.1.93. تحتفظ الإصدارات والملاحظات الأصلية التاريخية أعلاه بنطاقها الأصلي. لتثبيت المشروع عقد مستقل لكل عميل: تُعرض ملكية الملفات المثبّتة والاكتشاف الأصلي وتشغيل MCP أو النموذج منفصلةً. يرفض نطاق مشروع ChatGPT العملية صراحةً؛ وللأهداف الأخرى قيودها الخاصة على المكونات أو التجهيز أو إطار الاختبار.
