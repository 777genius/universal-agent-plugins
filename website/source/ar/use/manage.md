# صيانة الإضافات المثبّتة {#maintain-installed-plugins}

استخدم المثبّت لفحص حالة التثبيت المُدارة وتغييرها. عند تقصي مشكلة، احتفظ بمصدر الحزمة والعملاء المختارين والنطاق وهوية التثبيت مع التقرير. تستخدم الأمثلة التالية نطاق المستخدم ما لم تحدد مشروعًا صراحةً.

## افحص الوضع أولًا {#inspect-the-situation-first}

```bash
agentplugins list
agentplugins doctor
agentplugins outdated --all
```

يعرض `list` التثبيتات، ويشخّص `doctor` الحالة المُدارة، ويبحث `outdated` عن التحديثات المتاحة من دون تطبيقها. ولا يثبت أي منها سلامة خدمة بعيدة أو اكتمال مصادقة العميل.

| العَرَض | الخطوة التالية |
| --- | --- |
| الحزمة غير موجودة | ارجع إلى [البحث والتثبيت](./install). |
| الملفات المملوكة مفقودة أو تغيرت | راجع خطة إصلاح الحزمة ضمن النطاق المعني. |
| يتوفر إصدار أحدث من مصدر متابَع | راجع خطة تحديث. |
| يحتاج العميل إلى الثقة أو التفعيل أو تسجيل الدخول | اتبع تعليمات العميل التي أبلغ عنها الهدف. |
| تفشل الحزمة المحلية في التحقق | أعطِ المؤلف تقرير الحزمة و[إرشادات الفحص](../build/checks). |

## واجهة API للإدارة المحلية (CLI 0.1.95) {#local-management-api}

يضيف [CLI 0.1.95](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.95) الأمر `agentplugins manage serve` للتطبيقات التي تدمج المثبّت، والأمر `agentplugins manage discover` لاكتشاف العملاء وملفات التعريف المحلية للقراءة فقط. لا ينفّذ الاكتشاف العملاء، ولا يفحص إصداراتهم، ولا يجلب المصادر، ولا يغيّر الملفات.

`manage serve` عملية يدير التطبيق المضيف دورة حياتها، وتستخدم سياقًا يُلتقط عند بدء التشغيل وواجهة API خاصة ومصادَقًا عليها عبر عنوان استرجاع IPv4 محلي. يرسل المضيف JSON عبر stdin ويحافظ على خصوصية عنوان URL للتهيئة وقدرة التفويض bearer. افحص مساعدة الأوامر قبل الدمج:

```bash
agentplugins version
agentplugins manage serve --help
agentplugins manage discover --help
```

راجع [عقد بروتوكول الإدارة](https://github.com/777genius/universal-agent-plugins/blob/main/contracts/management/README.md) لقواعد بدء التشغيل ودورة الحياة. تُدار إصدارات [حزمة SDK للإدارة بلغة TypeScript](https://github.com/777genius/universal-agent-plugins/blob/main/sdks/typescript/README.md) بشكل مستقل باسم الحزمة `universal-agent-plugins-management-sdk`. راجع ملف README الخاص بها لمعرفة إصدارات محرك `agentplugins` المتوافقة وتعليمات تثبيت الحزمة. اختر إصدارًا منشورًا على npm، أو ابنِ حزمة واختبرها انطلاقًا من commit محدد وثابت للشيفرة المصدرية للعمل على تغييرات لم تُنشر بعد. ثبّت كلًّا من SDK والمحرك على إصدار محدد.

## حدّث عن قصد {#update-deliberately}

```bash
agentplugins update context7 --target codex,cursor --dry-run
```

راجع المصدر والإصدار والوجهات المختارة. احذف `--dry-run` للتطبيق:

```bash
agentplugins update context7 --target codex,cursor
```

يشمل `update --all` جميع التحديثات المتاحة للتثبيتات المُدارة. استخدمه عندما تكون المجموعة بأكملها هي النطاق المقصود. يبقى مصدر الالتزام الدقيق غير قابل للتغيير؛ ولا يجعله التحديث يتابع فرعًا. لا تتقدم نطاقات الاعتماديات المحفوظة والمراجع المتحركة إلا عبر عملية التحديث الصريحة المناسبة.

## أصلح الحالة المسجلة {#repair-recorded-state}

```bash
agentplugins repair context7 --target codex,cursor --dry-run
agentplugins repair context7 --target codex,cursor
```

يعاين الأمر الأول الخطة ويطبّقها الثاني. يعيد الإصلاح استخدام المصدر المسجل لاستعادة المحتوى المملوك. ولا يختار مراجعة بعيدة جديدة أو يستبدل بصمت إدخالات أصلية تغيّرت خارجيًا. راجع التعارضات وأي تعليمات استرداد معلّقة قبل المتابعة.

## أزل التثبيت المختار {#remove-the-selected-installation}

```bash
agentplugins remove context7 --target codex,cursor --dry-run
agentplugins remove context7 --target codex,cursor
```

راجع الخطة الأولى قبل تشغيل الأمر الثاني. تعتمد الإزالة على الملكية المسجلة لدى CLI. ولا تلغي حساب خدمة، أو تزيل بيئات تشغيل غير مرتبطة، أو تحذف مجلد مصدر المؤلف. تحتفظ إزالة المشروع افتراضيًا ببيانات الإضافة ومخزن المحتوى المشترك الذي تم التحقق منه.

## استخدم بيئة اعتماديات محفوظة {#use-a-saved-dependency-environment}

يسجل `uap.toml` الحزم والأهداف التي تريدها، ويسجل `uap.lock` مصادرها الدقيقة المحسومة وبصماتها. افحص البيئة المختارة باستخدام:

```bash
agentplugins deps status
agentplugins deps tree
```

لبيئة جديدة، استخدم `agentplugins deps init`، وعدّل ملف البيان بعناية، ثم شغّل `agentplugins deps lock` لحسم الاعتماديات و`agentplugins install --locked --scope user` لتطبيق القفل. راجع طلبات التأكيد واستخدم `--dry-run` للمعاينة. يشرح [دليل الاعتماديات](https://github.com/777genius/universal-agent-plugins/blob/main/docs/UAP_DEPENDENCIES.md) صيغة البيان واعتماديات الحزم الإلزامية ونطاقات الإصدارات وقواعد التحديث.

تحفظ عمليات `add` البعيدة المؤهلة تعريف الاعتماديات القابلة للنقل افتراضيًا في CLI 0.1.93. أما المسارات المحلية الصريحة ومصادر الاكتشاف والتجهيز الخاص بـ ChatGPT فقط و`--no-save` فتستخدم مسار التنفيذ المباشر. لا تفترض أن تثبيتًا مباشرًا أقدم مشمول بالاتفاق؛ افحص `deps status` والملفات الفعلية قبل نقلها.

## استعد على آلة أخرى {#restore-on-another-machine}

انقل بيئة مستخدم محفوظة عبر مجلد تبادل. من ذلك المجلد على الآلة المصدر:

```bash
agentplugins deps export
```

انسخ المجلد إلى الوجهة، وثبّت العملاء المستهدفين، ثم شغّل هناك:

```bash
agentplugins deps import
agentplugins install --locked --scope user
```

أو اجمع الاستيراد والاستعادة:

```bash
agentplugins deps import --install
```

تختار وسيطة المجلد الاختيارية مجلد تبادل آخر. تقرأ عملية التصدير بيئة المستخدم وتكتب عملية الاستيراد إليها؛ ويمكن استخدام `AGENTPLUGINS_HOME` لاختيار بيئة بعينها. ليس المجلد المنقول بحد ذاته بديلًا لملف تعريف العميل. يُبقي `--scope user` الصريح الاستعادة ضمن بيئة المستخدم.

لا يُنقل سوى `uap.toml` و`uap.lock` دون تغيير وبعد التحقق الصارم منهما. تعرض عملية النسخ الفعلية معاينة وتتطلب تأكيدًا أو `--yes`؛ ويعرض `--dry-run` المعاينة فقط. يعمل التحقق عند الاستيراد بلا اتصال، أما التثبيت فيحتاج إلى المصادر المسجلة أو الحزم المخزنة مؤقتًا التي جرى التحقق منها. تجلب الاستعادة دون ذاكرة مؤقتة المراجع المثبتة الدقيقة وتفحص بصماتها، ولا تختار إصدارات أحدث.

لا يشمل النقل ملفات تعريف العملاء أو الإعدادات أو بيانات الاعتماد أو الإيصالات أو `PLUGIN_DATA`. اضبط المصادقة على الآلة الجديدة وانسخ البيانات احتياطيًا بشكل منفصل. إذا فشل التثبيت بعد حفظ الملفين أثناء الاستيراد، فأصلح السبب المبلّغ عنه وأعد `install --locked --scope user`. شغّل `deps recover --scope user` أولًا إذا أُبلغ عن استرداد معلّق. لا تُعد إنشاء المراجع المنقولة باستخدام `deps lock`، لأن المحدد المتحرك قد يُحسم إلى نتيجة مختلفة.

## استعد مشروعًا وحافظ عليه {#restore-and-maintain-a-project}

يتوفر التثبيت التلقائي للمشروع في [CLI 0.1.94 وأحدث](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.94). أضف `uap.toml` و`uap.lock` الخاصين بالمشروع إلى نظام التحكم بالإصدارات. في نسخة عمل أخرى موجودة، ثبّت العملاء المطلوبين وشغّل الأمر من مجلد المشروع نفسه:

```bash
agentplugins install
```

يخضع القفل الموجود لتحقق صارم. ويشترط `--locked` وجوده أيضًا، مما يفيد في CI؛ أما دون قفل فيمكن للتثبيت الأول إنشاء واحد. عند تنفيذ الأمر من مجلد آخر، اختر المشروع الموجود صراحةً:

```bash
agentplugins install --locked --scope project --project-root /path/to/project
```

اختر النطاق والجذر نفسيهما للصيانة:

```bash
agentplugins list --scope project --project-root /path/to/project
agentplugins deps status --scope project --project-root /path/to/project
agentplugins repair review --target cursor --scope project --project-root /path/to/project
agentplugins deps recover --scope project --project-root /path/to/project
```

استخدم هوية التثبيت من `list` إذا كان الاسم ملتبسًا. تستخدم أوامر الصيانة نطاق المستخدم افتراضيًا، لذا اختر نطاق المشروع صراحةً. يتبع `install` دون وسيطة مصدر قاعدة اختيار 0.1.94 الموضحة أدناه. ويستخدم `--scope project` الصريح من دون `--project-root` مجلد تنفيذ الأمر فقط.

أبقِ إيصالات `.uap/` وسجلات الاسترداد والبيانات المحتفظ بها محلية. استعد المكونات الأصلية من الاتفاق القابل للنقل واتبع تعليمات الثقة أو التفعيل الخاصة بالعميل. يجب أن تظل المصادر وإمكانية الوصول إلى المصادر الخاصة متاحة. راجع [تثبيت المشاريع](https://github.com/777genius/universal-agent-plugins/blob/main/docs/PROJECT_INSTALLATION.md) و[حدود كل عميل](https://github.com/777genius/universal-agent-plugins/blob/main/docs/PROJECT_CLIENT_SUPPORT.md).

## الاختيار الافتراضي للتثبيت في CLI 0.1.94 {#default-install-selection-in-cli-0194}

تحقّق أولًا من `agentplugins version`. يتطلب هذا السلوك 0.1.94؛ وإذا كانت قناة مدير الحزم أقدم، فاستخدم المثبّت الأصلي أو Homebrew. تبقى أوامر نطاق المشروع الصريح أعلاه متوافقة مع 0.1.93.

**متاح في [CLI 0.1.94](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.94):** يختار `agentplugins install` دون وسيطة مصدر أو نطاق صريح نطاق المشروع إذا وُجد ملف عادي باسم `uap.toml` في المجلد الحالي نفسه. ولا يبحث في المجلدات الأب. يُرفض أثناء الاختيار التلقائي مجلد أو رابط رمزي بهذا الاسم؛ حدّد النطاق صراحةً لإزالة الالتباس. دون ذلك البيان المحلي، يختار التثبيت بيئة المستخدم. تكون الأولوية دائمًا لـ `--scope user` أو `--scope project` الصريح. وتستمر الأوامر الأخرى في استخدام نطاق المستخدم افتراضيًا.

يُتحقق من `uap.lock` الموجود بصرامة قبل التغييرات، حتى دون `--locked`. يوقف عدم التطابق العملية؛ استخدم `update` لتقديم المراجع المثبتة، ولا تتوقع أن يحدّثها install. لا يُسمح بحسم اعتماديات التثبيت الأول وإنشاء قفل إلا عند غياب القفل. ويشترط `--locked` وجود قفل مسبق أيضًا. تبقى أمثلة النطاق الصريح و`--locked` أعلاه مناسبة للأتمتة المتوقعة واستعادة المشاريع.

## أبلغ عن المشكلة بوضوح {#report-a-problem-clearly}

سجّل إصدار CLI والعملية والنطاق ومصدر الحزمة والعملاء المستهدفين وتعليمات التفعيل المتبقية. بيّن هل وقع الفشل أثناء جلب المصدر، أم التخطيط، أم تطبيق الملفات، أم الاسترداد، أم اكتشاف العميل، أم المصادقة، أم الاستخدام وقت التشغيل. أزل بيانات الاعتماد قبل مشاركة التشخيص. يفحص `doctor ./my-plugin` الخاص بالتأليف حزمة مصدر؛ أما `doctor` الخاص بالمثبّت فيشخّص حالة التثبيت المُدارة.
