# فهم جذر الحزمة {#understand-the-package-root}

**التأليف من المصدر:** تتطلب أوامر هذه الصفحة [بناءً من المصدر يدعم التأليف](./#build-from-source). لا يتضمن إصدار المثبّت الحالي `agentplugins author`.

المجلد المختار هو جذر الحزمة. تقرأ أدوات التأليف `plugin.json` الموجود في الجذر ومكوناته المعيارية. ولا تبحث في المجلدات الأب عن مشروع، ولا تلجأ إلى ملف بيان مخفي لعميل أصلي.

## البنية الدنيا والبنية المدمجة {#minimal-and-combined-layouts}

حزمة تحتوي على Skill فقط:

```text
review-helper/
  plugin.json
  skills/
    review-docs/
      SKILL.md
```

حزمة هجينة بعيدة:

```text
research-helper/
  plugin.json
  mcp.json
  skills/
    research-guide/
      SKILL.md
```

تحمل حزمة stdio أيضًا مصدر التشغيل وملفات بيان الاعتماديات. تلزم هذه الملفات للتنفيذ لاحقًا، لكن وجودها لا يدفع قارئ التأليف إلى تنفيذ شيء.

## اجعل مسؤولية كل ملف واضحة {#give-each-file-a-clear-responsibility}

| الملف أو المجلد | المسؤولية |
| --- | --- |
| `plugin.json` | هوية الحزمة المعيارية وبياناتها الوصفية. |
| `mcp.json` | إعدادات خادم MCP عندما توفر الحزمة أدوات. |
| `skills/<name>/SKILL.md` | هوية Skill واحدة موضوعة مباشرةً تحت `skills/` ووصفها وتعليماتها. |
| `README.md` | الاستخدام المقصود والمتطلبات المسبقة والتحقق والحدود المتبقية. |
| `package.json`, `package-lock.json`, `src/server.mjs` | مدخلات هيكل Node عبر stdio لعمل تشغيل منفصل. |
| `LICENSE` | الترخيص المختار صراحةً عند تقديمه أثناء init. |

يبدأ الهيكل المولّد إصدار البيان عند `0.1.0`. هذه بيانات الحزمة الجديدة، وليست إصدار الملف التنفيذي للتأليف. حافظ على هذا التمييز عند إبلاغ المستخدمين بالإصدارات.

## الهوية والبيانات الوصفية الاختيارية {#identity-and-optional-metadata}

استخدم `--name` و`--description` صراحةً في تعليمات init القابلة للتكرار. يستطيع العقد العام اشتقاق اسم من اسم وجهة مجرد ويوفر وصفًا افتراضيًا حتميًا، لكن المسارات مثل `./review-helper` ينبغي أن تحمل اسمًا صريحًا. تقدم هذه الدروس كليهما لتجنب اختيار هوية عرضيًا.

للقوالب التي تضم Skill، تكون القيمة الافتراضية لـ `--skill-name` هي اسم الحزمة عند حذفه. اختره صراحةً إذا احتاجت Skill إلى هوية مختلفة. لا تُطبّع أسماء Skills بصمت مطلقًا.

يحدد `--author-name` الاختياري مؤلفًا صريحًا. ولا يُستنتج المؤلف من Git أو البيئة. يدعم توليد الترخيص اختيار MIT أو ISC صراحةً، ويتطلب `--copyright-holder` و`--copyright-year` من أربعة أرقام معًا. لا يوجد اختيار افتراضي للترخيص.

## اختر الجذر نفسه باستمرار {#select-the-root-consistently}

```bash
agentplugins author validate ./research-helper
agentplugins author inspect ./research-helper
agentplugins author test ./research-helper
```

تختار الأوامر الثلاثة جذر الحزمة نفسه. تمرير `./research-helper/skills` يختار المجلد الخطأ. يقتصر المسار الافتراضي الاختياري لأوامر القراءة على المجلد الحالي، وليس مجلدًا أب جرى اكتشافه.

المطابقة المعيارية وسلامة نظام الملفات مسألتان منفصلتان. فقد تكون الهوية صالحة وفق المخطط لكنها غير مناسبة لمسار المضيف، وقد يترك ملف بيان مقروء وحده أدلة المكونات المطلوبة غير مكتملة. اعتمد التقرير الكامل.
