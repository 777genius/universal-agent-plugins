## Обслуживание проекта в текущем исходном коде

**Только сборка из исходников; функция ещё не выпущена.** `agentplugins install`
без аргумента выбирает проект, если обычный файл `uap.toml` находится прямо в
текущем каталоге; родительские каталоги не проверяются. Явный `--scope` имеет
приоритет. Существующий `uap.lock` строго проверяется до изменений; только его
отсутствие допускает первоначальное разрешение зависимостей. `--locked` требует
наличия lock-файла. Для обновления закреплённых версий используйте `update`.
Предпросмотр показывает область и пути файлов соглашения. В остальных командах
обслуживания явно выбирайте проект:

[Команды обслуживания приведены в английском разделе](/en/use/manage#maintain-a-project-in-the-current-source).

Для совместного использования зависимостей сохраняйте переносимые `uap.toml`
и `uap.lock` в системе контроля версий. Записи владения, восстановление и данные
в `.uap/` остаются локальными; данные копируйте отдельно. Удаление сохраняет
данные и общий кэш содержимого. Repair восстанавливает отсутствующие компоненты
и повреждённые управляемые пакеты; изменённые файлы агента требуют проверки.
Восстановление выполняйте для исходного выбранного проекта.
