# Матрица проверок клиентов UAP

[Каноническая матрица на английском](/en/reference/client-compatibility)
разделяет валидность пакета, установку, активацию, runtime и OAuth.
Для каждого результата указаны версии клиентов, платформа и идентификатор
проверенного исходного кода. Проверки сборки из исходников не означают,
что эти изменения уже вошли в опубликованный релиз.

## Черновая версия установщика 0.1.55

**0.1.55 — неопубликованный черновик.** Результаты относятся к зафиксированным снимкам черновика; это не объявление релиза и не инструкция по обновлению. Доказательства для выпущенной 0.1.53 остаются действительными и отдельными.

В двух отдельно квалифицированных наборах **прошли все 12 проверок сочетаний клиента и платформы и 24 обязательных теста верхнего уровня без пропусков**. Использовался исходный npm-архив сборки производителя: установка npm выполнялась офлайн с отключёнными скриптами, затем проверялись холодный запуск с зафиксированным нативным бинарным файлом и повторный запуск без источника бинарного файла для проверки. Настоящие клиенты закреплённых версий запускались в новых одноразовых профилях.

| Проверенный клиент | Linux arm64 | Linux amd64 | macOS arm64 | Windows amd64 |
| --- | --- | --- | --- | --- |
| Codex 0.153.4 | Пройдены жизненный цикл, stdio/HTTP и контекст навыка | Тот же объём пройден | Тот же объём пройден | Тот же объём пройден |
| Claude Code 2.1.263 | Пройдены жизненный цикл, stdio/HTTP и установленные навыки | Тот же объём пройден | Тот же объём пройден | Пройдены HTTP и жизненный цикл установленных навыков; управляемый stdio не поддерживается |
| OpenCode 1.18.29 | Пройдены жизненный цикл, расширенные stdio/навыки и наблюдение коллизий | Тот же объём пройден | Тот же объём пройден | Тот же объём пройден |

Жизненный цикл включает установку, обновление версии, повторную установку той же версии, восстановление и удаление. Claude на Windows сообщает `managed_stdio_platform_unsupported`; выполнение через stdio и поведение cwd/argv/env/data не подтверждены. Наблюдаемая коллизия OpenCode не устранена; сохраняется предупреждение `opencode_tool_namespace_not_evaluated`. Жизненный цикл JSONC не доказывает выполнение stdio или передачу тела навыка через JSONC. Проверка получения пакета через Git в наборе Codex не является новым доказательством нативного выполнения из публичного Git.

[Запуск historical-nine](https://github.com/777genius/universal-agent-plugins/actions/runs/34309083566) прошёл девять сочетаний и 18 обязательных тестов с проверочным кодом `0cfa2b7`; финальная перепроверка черновика: **2026-09-09T04:10:39.529018+00:00**. [Запуск Linux amd64](https://github.com/777genius/universal-agent-plugins/actions/runs/34307075390) прошёл три сочетания и шесть обязательных тестов с проверочным кодом `fde7298`; финальная перепроверка: **2026-09-09T03:36:42.614887+00:00**. Оба набора привязаны к одной зафиксированной [сборке производителя](https://github.com/777genius/universal-agent-plugins/actions/runs/34305637370). [Компактная запись метаданных](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/client-compatibility-draft-0.1.55.json) содержит точные идентификаторы производителя, пакета, проверочного кода, квалификаций и архивов.

Оба сохранённых набора прошли офлайн-проверку. Верификатор из новой копии исходников `0cfa2b7` также перепроверил сохранённый набор Linux amd64 с идентичностью `fde7298`. Это не новый нативный запуск и не проверка текущего черновика; новое время квалификации из этого не следует. Совпадение хешей архива не означает свежую проверку аттестаций или подтверждение текущего состояния черновика. Исходные журналы и архивы сохраняются приватно до проверки допустимости раскрытия; публичны только метаданные.

Это наблюдения сопровождающих проекта: настоящие клиенты использовали сценарные провайдеры моделей на loopback-адресах при доступной сети. Одноразовые профили и явно заданное окружение дочерних процессов не обеспечивают изоляцию ОС или процессов. Результаты не подтверждают работу реальной модели, OAuth/вход, настольные приложения, внешние сервисы, сертификацию поставщика, официальный статус или независимое использование. Валидность пакета, установка, активация, выполнение и OAuth остаются отдельными уровнями доказательств. Эта проверка установщика не квалифицирует выпуск стандартного исполняемого инструмента авторинга (D5).
