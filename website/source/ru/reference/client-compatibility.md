# Матрица проверок клиентов UAP

## Текущий выпуск и область результатов

[CLI 0.1.93](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.93),
опубликованный 26 октября 2026 года, включает явную установку в проект и
восстановление по lock-файлу. Выпуск установщика не квалифицирует исполнение
в любом агенте или стандартный исполняемый инструмент разработки пакетов.
В нынешнем npm- и нативном установщике нет `agentplugins author`; средства из
исходного кода описаны в [руководстве по созданию](../build/).

Совместимость состоит из отдельных вопросов:

| Проверка | Значение |
| --- | --- |
| Соответствие пакета | Стандартные файлы соответствуют контракту загрузчика и схем. |
| Доставка компонентов | Адаптер подготовил или установил компоненты, которыми владеет. |
| Нативное обнаружение | Конкретный клиент увидел нужный компонент. |
| Исполнение MCP | Зафиксированные процесс или соединение прошли инициализацию и проверенные вызовы. |
| Аутентификация и модель | Подтверждаются только при явной проверке в соответствующем запуске. |

Проектный результат часто остаётся **Prepared**, пока нужны доверие, перезапуск,
явная конфигурация или новый сеанс. Проектная установка ChatGPT не поддерживается.
VS Code подготавливает файлы одной локальной папки; наблюдение метаданных
не доказывает запуск MCP или модели. См.
[поддержку проектов по клиентам](https://github.com/777genius/universal-agent-plugins/blob/main/docs/PROJECT_CLIENT_SUPPORT.md)
и [указатель проектных проверок](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/PROJECT_INSTALLATION.md).

Ниже сохранены версии, платформы и ограничения исторических запусков.
Результат не переносится автоматически на 0.1.93, другой клиент, область или
пакет. UAP — независимый общественный проект. Наблюдения сопровождающих
не являются сертификацией поставщиков или обещанием полной готовности для
любого производственного сценария.

## Исторический черновик установщика 0.1.55

**На зафиксированном этапе сентября 2026 года 0.1.55 был неопубликованным черновиком.** Результаты относятся к тем снимкам; это не описание нынешнего статуса выпуска и не инструкция по обновлению. Доказательства для выпущенной 0.1.53 остаются действительными и отдельными.

В двух отдельно квалифицированных наборах **прошли все 12 проверок сочетаний клиента и платформы и 24 обязательных теста верхнего уровня без пропусков**. Использовался исходный npm-архив сборки производителя: установка npm выполнялась офлайн с отключёнными скриптами, затем проверялись холодный запуск с зафиксированным нативным бинарным файлом и повторный запуск без источника бинарного файла для проверки. Настоящие клиенты закреплённых версий запускались в новых одноразовых профилях.

| Проверенный клиент | Linux arm64 | Linux amd64 | macOS arm64 | Windows amd64 |
| --- | --- | --- | --- | --- |
| Codex 0.153.4 | Пройдены жизненный цикл, stdio/HTTP и контекст навыка | Тот же объём пройден | Тот же объём пройден | Тот же объём пройден |
| Claude Code 2.1.263 | Пройдены жизненный цикл, stdio/HTTP и установленные навыки | Тот же объём пройден | Тот же объём пройден | Пройдены HTTP и жизненный цикл установленных навыков; управляемый stdio не поддерживается |
| OpenCode 1.18.29 | Пройдены жизненный цикл, расширенные stdio/навыки и наблюдение коллизий | Тот же объём пройден | Тот же объём пройден | Тот же объём пройден |

Жизненный цикл включает установку, обновление версии, повторную установку той же версии, восстановление и удаление. Claude на Windows сообщает `managed_stdio_platform_unsupported`; выполнение через stdio и поведение cwd/argv/env/data не подтверждены. Наблюдаемая коллизия OpenCode не устранена; сохраняется предупреждение `opencode_tool_namespace_not_evaluated`. Жизненный цикл JSONC не доказывает выполнение stdio или передачу тела навыка через JSONC. Проверка получения пакета через Git в наборе Codex не является новым доказательством нативного выполнения из публичного Git.

[Запуск historical-nine](https://github.com/777genius/universal-agent-plugins/actions/runs/34309083566) прошёл девять сочетаний и 18 обязательных тестов с проверочным кодом `0cfa2b7`; финальная перепроверка черновика: **2026-09-09T04:10:39.529018+00:00**. [Запуск Linux amd64](https://github.com/777genius/universal-agent-plugins/actions/runs/34307075390) прошёл три сочетания и шесть обязательных тестов с проверочным кодом `fde7298`; финальная перепроверка: **2026-09-09T03:36:42.614887+00:00**. Оба набора привязаны к одной зафиксированной [сборке производителя](https://github.com/777genius/universal-agent-plugins/actions/runs/34305637370). [Компактная запись метаданных](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/client-compatibility-draft-0.1.55.json) содержит точные идентификаторы производителя, пакета, проверочного кода, квалификаций и архивов.

Оба сохранённых набора прошли офлайн-проверку. Верификатор из новой копии исходников `0cfa2b7` также перепроверил сохранённый набор Linux amd64 с идентичностью `fde7298`. Это не новый нативный запуск и не проверка текущего черновика; новое время квалификации из этого не следует. Совпадение хешей архива не означает свежую проверку аттестаций или подтверждение текущего состояния черновика. Исходные журналы и архивы сохраняются приватно до проверки допустимости раскрытия; публичны только метаданные.

Это наблюдения сопровождающих проекта: настоящие клиенты использовали сценарные провайдеры моделей на loopback-адресах при доступной сети. Одноразовые профили и явно заданное окружение дочерних процессов не обеспечивают изоляцию ОС или процессов. Результаты не подтверждают работу реальной модели, OAuth/вход, настольные приложения, внешние сервисы, сертификацию поставщика, официальный статус или независимое использование. Валидность пакета, установка, активация, выполнение и OAuth остаются отдельными уровнями доказательств. Эта проверка установщика не квалифицирует выпуск стандартного исполняемого инструмента авторинга (D5).

## Исторический выпущенный установщик 0.1.53

[Публичный выпуск 0.1.53](https://github.com/777genius/universal-agent-plugins/releases/tag/agentplugins-v0.1.53)
использует commit установщика `28cf05af0a1e4fea642825dd34b78f9c99094ab5`.
[Нативный запуск 34166817934](https://github.com/777genius/universal-agent-plugins/actions/runs/34166817934)
прошёл все девять заданий и 18 обязательных тестов без пропусков. Публичные
бинарные файлы были загружены и проверены по манифесту и аттестациям до запуска;
вспомогательные инструменты имели отдельный commit
`9c33cfac81fc00e61205591321c89c5675fedb60`.

| Клиент | Linux arm64 | macOS arm64 | Windows amd64 |
| --- | --- | --- | --- |
| Codex 0.153.4 | Жизненный цикл, stdio/HTTP и контекст Skill пройдены | Тот же объём | Тот же объём |
| Claude Code 2.1.263 | Жизненный цикл stdio/HTTP/Skills пройден | Тот же объём | HTTP и установленные Skills пройдены; управляемый stdio не поддерживается |
| OpenCode 1.18.29 | Жизненный цикл, наблюдение коллизий и расширенные stdio/Skills пройдены | Тот же объём | Тот же объём |

Клиенты настоящие, но провайдеры моделей — сценарные loopback-сервисы.
Это не проверка реальной модели, OAuth, входа в сервис или настольного
приложения. Для OpenCode stdio и тело Skill проверены в глобальном JSON;
жизненный цикл JSONC не подтверждает такой же объём исполнения. Наблюдение
коллизии имён инструментов остаётся ограничением, а не обещанием решения.

[Метаданные и хеши](https://github.com/777genius/universal-agent-plugins/blob/main/docs/evidence/client-compatibility-released-0.1.53.json)
содержат точные идентичности. [Отдельный выпуск доказательств](https://github.com/777genius/universal-agent-plugins/releases/tag/native-evidence-0.1.53-34166817934)
хранит проверенный архив; он не изменяет неизменяемый выпуск установщика.
[Порядок воспроизведения и публикации](https://github.com/777genius/universal-agent-plugins/blob/main/docs/released-native-client-proof.md)
описывает границы проверки.

Снимок от 7 сентября 2026 года описывает отдельные исходные сборки. Для macOS

## Проектная область

Явная доставка компонентов проекта выпущена в CLI 0.1.93. У неё отдельный
контракт для каждого клиента: владение файлами, нативное обнаружение и работа
MCP/модели фиксируются раздельно. Запрос проекта ChatGPT явно отклоняется;
остальные клиенты имеют собственные границы компонентов и активации.

VS Code использует `.github/skills` и `.vscode/mcp.json`.
[Наблюдение VS Code 1.143.1](https://github.com/777genius/universal-agent-plugins/actions/runs/40188310034)
проверило метаданные в отдельных папках A/B, свежий запуск A и удаление при
непредоставленном доверии к папке. Адаптер сообщает Prepared и проверку файлов,
без утверждения о запуске MCP, вызовах инструментов или модели.
