# Создать пакет с одним Skill

**Средства из исходного кода:** команды на этой странице требуют
[соответствующей сборки](./#build-from-source). В текущем установщике нет
`agentplugins author`.

Выберите этот путь для повторяемой методики, чек-листа или требований к тексту,
когда MCP-инструменты не нужны. Для описанных шагов создания не требуются
сервер, установка зависимостей или профиль клиента.

## Явно выберите каталог

В примерах текущая папка — родительский каталог, а `./review-helper` ещё не
существует. Путь задаёт место создания, `--name` — имя пакета в манифесте.
Выберите переносимое имя в нижнем регистре.

```bash
agentplugins author init ./review-helper \
  --template skill \
  --name review-helper \
  --description 'Проверка ясности и обоснованности документации' \
  --skill-name review-docs
```

Init не перезаписывает существующий каталог. Если отчёт говорит о сохранённом
результате (`committed`) и последующей ошибке, сначала изучите созданные файлы.
Повторный запуск не является способом перезаписи.

## Изучите файлы

```text
review-helper/
  plugin.json
  README.md
  .gitignore
  skills/
    review-docs/
      SKILL.md
```

Замените тело созданного Skill конкретной методикой. Имя Skill должно
соответствовать его каталогу. Например:

```markdown
# Проверка документации

Используйте этот Skill для проверки изменений документации перед передачей.

1. Определите читателя и задачу страницы.
2. Проверьте входные данные и действие каждой команды.
3. Отделите подтверждённое поведение от требований и непроверенных заявлений.
4. Верните неясные инструкции с предложенной заменой.

Верните краткий список замечаний с расположением в файлах. Если замечаний нет,
укажите проверенные страницы и проверки, которые не выполнялись.
```

Сохраните созданный блок frontmatter над телом: `name` и `description` помогают
агенту выбирать Skill. Текст Skill сам по себе не даёт разрешение запускать
скрипты или обращаться к закрытым ресурсам.

## Проверьте точный корень

```bash
agentplugins author validate ./review-helper
agentplugins author skills validate ./review-helper
agentplugins author inspect ./review-helper
agentplugins author test ./review-helper
```

Проверки статические: они не просят агента выполнить инструкции и не оценивают
качество его ответа. Читайте соответствие формату и общую готовность отдельно.
Полезность, точность и границы инструкций также требуют человеческой проверки.

Далее: [дополнительные Skills](./skills), [проверки](./checks) или
[передача установщику](./handoff). Для инструментов вместе с инструкциями выберите
[гибридный шаблон](./hybrid).
