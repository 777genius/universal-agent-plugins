# Добавить Skills

**Средства из исходного кода:** команды требуют
[соответствующей сборки](./#build-from-source). В текущем установщике нет
`agentplugins author`.

`skills init` добавляет один Skill в существующий стандартный пакет: с
инструкциями, MCP или обоими компонентами. Выбирайте корень с `plugin.json`,
а не каталог `skills/` и не отдельный `SKILL.md`.

## Укажите имя и пакет

Допустим, `./review-helper` создан по [руководству Skill](./skill), а
`skills/release-notes/` ещё не существует:

```bash
agentplugins author skills init release-notes ./review-helper \
  --description 'Используйте для подготовки заметок о выпуске из проверенных изменений'
```

Позиционное имя Skill и явное описание от 1 до 1024 символов обязательны.
Имена не нормализуются. Выберите точное переносимое имя в нижнем регистре с
дефисами и новый каталог вместо ожидания перезаписи.

## Изучите новый компонент

```text
review-helper/
  plugin.json
  skills/
    review-docs/
      SKILL.md
    release-notes/
      SKILL.md
```

В `skills/release-notes/SKILL.md` опишите условия использования, методику и
ожидаемый результат. Например, попросите отделять видимые пользователям
изменения от обслуживания и указывать проверенный источник каждого утверждения.

Скрипты, справочные материалы и ресурсы могут помогать инструкциям. Их наличие
не подтверждает выполнение и не даёт разрешение на запуск. `allowed-tools`
также не является самостоятельным разрешением. Проверяйте сопутствующие файлы
так же внимательно, как текст Skill.

## Проверьте пакет и его Skills {#проверьте-пакет-и-непосредственные-skills}

```bash
agentplugins author skills validate ./review-helper
```

Команда показывает общую готовность пакета и отдельные результаты для
Skills, расположенных в подпапках первого уровня внутри `skills/`.
Ошибка в другом компоненте может повлиять на общий
результат, даже если новый Skill корректен.

Без пути выбирается только текущая папка, без поиска родителей. Явный корень
делает автоматизацию и диагностику понятнее. Запуск из `skills/release-notes/`
не заменяет выбор корня пакета.

## Разберите ошибку без перезаписи

Если создание не удалось, прочитайте `committed` и указания. Файлы Skill могут
быть сохранены до ошибки последующей проверки. Изучите файлы и отчёт перед
повтором: существующий каталог не будет перезаписан.

Исправьте указанные данные или проблему пакета и повторите проверку.
Установку и обслуживание чужих Skills выполняет отдельный установщик;
`author skills` редактирует и проверяет компоненты вашего исходного пакета.

Далее: [проверки](./checks) и [передача](./handoff).
