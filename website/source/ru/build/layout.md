# Структура корня пакета

**Средства из исходного кода:** команды требуют
[соответствующей сборки](./#build-from-source). В текущем установщике нет
`agentplugins author`.

Выбранный каталог — корень пакета. Средства разработки читают корневой
`plugin.json` и стандартные компоненты. Они не ищут проект в родительских папках
и не подменяют его скрытым манифестом отдельного клиента.

## Минимальная и объединённая структура

Пакет с одним Skill:

```text
review-helper/
  plugin.json
  skills/
    review-docs/
      SKILL.md
```

Гибридный пакет с удалённым MCP:

```text
research-helper/
  plugin.json
  mcp.json
  skills/
    research-guide/
      SKILL.md
```

Пакет stdio также содержит исходный код и манифесты зависимостей. Они нужны
для отдельного запуска, но само чтение пакета не исполняет их.

## Назначение файлов

| Файл или каталог | Назначение |
| --- | --- |
| `plugin.json` | Стандартная идентичность и метаданные пакета. |
| `mcp.json` | Конфигурация MCP-серверов, если пакет предоставляет инструменты. |
| `skills/<name>/SKILL.md` | Имя, описание и инструкции одного Skill в подпапке первого уровня внутри `skills/`. |
| `README.md` | Назначение, требования, результаты проверок и ограничения. |
| `package.json`, `package-lock.json`, `src/server.mjs` | Файлы Node-шаблона для отдельной работы с исполнением. |
| `LICENSE` | Явно выбранная лицензия, если она задана при init. |

В созданном манифесте версия начинается с `0.1.0`. Это версия вашего пакета,
а не выпуск исполняемого файла разработчика. Не смешивайте эти значения в отчётах.

## Идентичность и необязательные метаданные

Указывайте `--name` и `--description` в воспроизводимых командах init.
Публичный контракт умеет брать имя из простого имени назначения и выбирать
детерминированное описание по умолчанию. Для путей вроде `./review-helper`
используйте явное имя. В примерах оба поля указаны.

Для шаблонов со Skill `--skill-name` по умолчанию равен имени пакета. Задайте
его отдельно, если Skill нужно другое имя. Имена Skills не нормализуются скрыто.

`--author-name` задаёт автора явно, без вывода из Git или окружения. Создание
лицензии поддерживает явный выбор MIT или ISC и требует `--copyright-holder`
и четырёхзначный `--copyright-year`. Лицензия по умолчанию не выбирается.

## Выбирайте один корень последовательно

```bash
agentplugins author validate ./research-helper
agentplugins author inspect ./research-helper
agentplugins author test ./research-helper
```

Все команды указывают один корень. `./research-helper/skills` было бы неверным
каталогом. Необязательный путь команд чтения по умолчанию означает только
текущую папку, без поиска родителей.

Соответствие стандарту и безопасность путей — разные вопросы. Имя, корректное
по схеме, может быть неприемлемым для пути на хосте; читаемого манифеста может
быть недостаточно для всех компонентов. Изучайте весь отчёт.
