## plugin-kit-ai skills list

List external Agent Skills through the npm skills CLI

```
plugin-kit-ai skills list [flags]
```

### Options

```
  -a, --agent strings               filter by agent(s)
  -g, --global                      list global skills instead of project skills
  -h, --help                        help for list
      --json                        output JSON from the upstream skills CLI
      --skills-cli-version string   npm skills CLI version to run (default "1.5.5")
```
