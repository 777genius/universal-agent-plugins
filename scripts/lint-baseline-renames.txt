# Path renames applied to the base revision before the shrink-only comparison in
# scripts/check-lint-baseline.sh.
#
# A `git mv` of an already-exempt file looks identical to a brand new exemption:
# the old path disappears and an unknown one appears. That is the one case where
# the baseline may legitimately name a path it did not name before, so each move
# is declared here instead of silently widening the gate. A line grants nothing
# on its own - the entry still has to be the same linters and the same message
# patterns the old path already carried, or the comparison fails as before.
#
# Format: <old path pattern><TAB or spaces><new path pattern>, both exactly as
# written in the `- path:` keys of .golangci.yml.

# Part 2: providers/nativeconfig is a generic CAS kernel with no dependency on
# providers, moved under adapters so the clients contract can reach it.
^install/integrationctl/agentplugins/providers/nativeconfig/kernel\.go$	^install/integrationctl/agentplugins/adapters/nativeconfig/kernel\.go$
^install/integrationctl/agentplugins/providers/nativeconfig/project\.go$	^install/integrationctl/agentplugins/adapters/nativeconfig/project\.go$
